BETWEEN THE LINES — Version 5

A bilingual, local interactive retrospective based on the WhatsApp export through 30 October 2026.

Files:
- index.html: main website
- styles.css: layout and styling
- script.js: language toggle, section navigation, and moment filters

Open index.html in a modern browser. No server or installation is required.

Chinese is the default language. Use the top-right toggle to switch to English.
The site focuses on chat patterns, memorable moments, the recurring “妈宝男” joke, ex-related conversations, everyday life, and playful MBTI/zodiac guesses. It avoids conclusions about private romantic feelings.

Note: call durations and message statistics are estimates based on the WhatsApp export and its displayed values.
